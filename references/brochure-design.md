# 골프장 홍보 브로슈어 디자인 가이드 (여행 상품 전단 스타일)

하나투어 같은 여행 상품 홍보물의 문법을 빌려 오되, 정보는 SKILL.md 5장과 같은 검증된 값만 쓴다.

## 1. 페이지 구성 (위에서 아래로)

1. **히어로**: 큰 제목("분당 출발 1시간 30분, 이번 주말 라운딩 BEST 3"), 부제, 기준일·출발지 배지, 배경은 그라디언트 + 골프 코스 SVG 일러스트.
2. **한눈에 보기 띠**: 이동시간·비용대·만족도를 아이콘 칩으로 3~4개.
3. **TOP 3 카드**: 순위 리본(1·2·3위), 골프장명, 위치, 분당 기준 이동, 1인 비용, 평점(출처), 추천 대상 한 줄.
4. **골프장별 상세 섹션**: 이미지 영역 + 포인트 3개(장점) + 알아두면 좋은 점(단점) + 주변 맛집 3곳 이상 카드.
5. **비교표**: 전체 후보 5~8곳.
6. **예약 팁 + 유의사항**: 가격·영업 정보는 변동되므로 공식 채널 확인.

## 2. 시각 규칙

- 색: 짙은 그린(#0f5132 계열) + 하늘색 포인트 + 따뜻한 오렌지(가격·CTA 강조). 배경은 밝은 톤.
- 서체: 시스템 한글 폰트 스택(`Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, sans-serif). 제목은 굵게, 본문은 15~16px.
- 가격은 크게, 단위·조건(평일/주말, 확인일)은 작게 같은 줄에 둔다.
- 칩/배지로 정보를 묶는다: `대중제`, `18홀`, `분당 55분`.
- 카드 모서리 둥글게, 그림자 약하게. 정보 밀도는 높이되 줄 간격은 1.5 이상.

## 3. 이미지 처리

- 파일에는 **외부 이미지를 직접 링크하거나 복사해 넣지 않는다.** 게시되는 HTML 페이지는 외부 이미지가 차단되고, 골프장·블로그 사진은 저작권 문제가 있다.
- 이미지 자리는 `.photo` 블록으로 만든다. 기본은 그라디언트 + SVG(페어웨이, 깃발, 나무, 구름)이며, 사용자가 사진을 주면 `<img src="data:...">`로 인라인한다. 템플릿의 `data-photo-slot` 주석 위치를 쓴다.
- 채팅에서는 이미지 검색 도구로 골프장 전경 등을 참고용으로 보여 줄 수 있다. 이 이미지는 파일에 포함하지 않는다.
- 사용자에게 한 줄로 안내한다: "실제 사진은 공식 홍보 이미지나 직접 찍은 사진을 넣으면 가장 좋습니다."

## 4. 문구 톤

- 여행 상품처럼 활기 있게 쓰되 근거를 붙인다: "후기에서 그린 상태 칭찬이 반복"(출처명), "분당에서 약 50분(지도 기준)".
- 금지: "무조건", "최고", 확인되지 않은 수치, 출처 없는 평점, 단점 삭제.
- 단점은 "알아두면 좋아요" 박스로 순하게 쓰되 내용은 그대로 유지한다.

## 5. 접근성·인쇄

- 본문 대비 4.5:1 이상. 색만으로 정보를 구분하지 않는다(순위는 숫자 병기).
- 인쇄용이면 `@media print`로 배경 그라디언트를 단순화하고 카드가 페이지 중간에 잘리지 않게 `break-inside: avoid`.
- 모바일 폭(360px)에서 가로 스크롤이 생기지 않아야 한다. 표는 `overflow-x: auto` 컨테이너에 넣는다.
